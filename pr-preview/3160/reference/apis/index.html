    APIs¶

    Interactive API documentation¶

    The OpenAPI specifications of each release are published as Swagger UI. They merge the upstream EDC APIs with the Tractus-X additions.

    Runtime Swagger UI
    Control plane openapi/control-plane-api
    Data plane openapi/data-plane-api

    Specifications of a specific release live under a version folder, for example https://eclipse-tractusx.github.io/tractusx-edc/openapi/control-plane-api/0.13.0/control-plane.yaml. To generate them locally run ./gradlew resolve; the YAML files appear under resources/openapi/yaml/.

    Ports and paths in the Helm chart¶

    API context Port Path Who calls it Expose?
    default 8080 /api Kubernetes probes no
    management 8081 /management Your applications internal only
    control 8083 /control Data plane no
    protocol 8084 /api/v1/dsp Other connectors (DSP) yes, via ingress
    metrics 9090 /metrics Monitoring no
    API context Port Path Who calls it Expose?
    default 8080 /api Kubernetes probes no
    public 8081 /api/public Consumers fetching data, token refresh yes, via ingress
    control 8084 /api/control Control plane no
    proxy 8186 /proxy Your applications (consumer proxy) internal only
    metrics 9090 /metrics Monitoring no

    The DSP protocol endpoint has a sub-path per protocol version: DSP 2025-1 under /api/v1/dsp/2025-1, DSP 0.8 at /api/v1/dsp. Partners can discover the supported versions at /api/v1/dsp/.well-known/dspace-version.

    Management API¶

    The Management API (control plane, /management) is the upstream EDC API plus a few Tractus-X endpoints. Authenticate with the X-Api-Key header, or with a JWT when delegated authentication (jwksUrl) is configured.

    Upstream resource Path
    Assets /v3/assets
    Policy definitions /v3/policydefinitions
    Contract definitions /v3/contractdefinitions
    Catalog /v3/catalog/request, /v3/catalog/dataset/request
    Contract negotiations /v3/contractnegotiations
    Contract agreements /v3/contractagreements
    Transfer processes /v3/transferprocesses

    The Management API walkthrough explains each of them with examples.

    Endpoints added by Tractus-X¶

    Method Path Plane / context Purpose
    POST /v3/edrs Control plane, Management API Negotiate and start a transfer in one call
    POST /v3/edrs/request Control plane, Management API Query cached EDRs
    GET /v3/edrs/{transferProcessId}/dataaddress?auto_refresh=true Control plane, Management API Get a (refreshed) EDR
    POST /v3/edrs/{transferProcessId}/refresh Control plane, Management API Force a token refresh
    DELETE /v3/edrs/{transferProcessId} Control plane, Management API Remove a cached EDR
    POST, PUT /v3/business-partner-groups Control plane, Management API Assign a BPN to groups
    GET /v3/business-partner-groups/{bpn}, /group/{group}, /groups Control plane, Management API Read groups
    DELETE /v3/business-partner-groups/{bpn} Control plane, Management API Remove a BPN
    POST /v3/contractagreements/retirements Control plane, Management API Retire an agreement early
    POST /v3/contractagreements/retirements/request Control plane, Management API List retired agreements
    DELETE /v3/contractagreements/retirements/{agreementId} Control plane, Management API Reactivate an agreement
    POST /v3/connectordiscovery/dspversionparams Control plane, Management API Find the DSP version and address of a connector
    POST /v3/connectordiscovery/connectors Control plane, Management API Find the connectors of a participant
    POST /v3/dataflows/{id}/trigger Data plane, management Re-trigger a non-finite push data flow
    POST /aas/request Data plane, consumer proxy (/proxy) Fetch data through the consumer proxy
    POST /token Data plane, public API Refresh an access token
    any /{path} Data plane, public API Provider data access with an EDR token

    Deprecated v4alpha paths

    /v4alpha/connectordiscovery/* and /v4alpha/dataflows/{id}/trigger are deprecated since 0.13.0. Use the v3 paths above.

    To list the endpoints of your checkout, run the Sensei's inventory script:

    .claude/skills/management-api-endpoint/scripts/api-inventory.sh
